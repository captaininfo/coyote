Good First Issues

Jump in with well-scoped starter tasks. Each card includes why it matters, steps, and a clear Definition of Done.

View live issues on GitHub

How we label & scope

  • Components: component:nlp, component:ingest, component:graph, component:ui, docs.
  • Difficulty: good first issue (≤2 hours) or help wanted (½–2 days).
  • Every issue includes: repro steps, acceptance criteria, file paths, and a short test plan.

Docs: 90-second “happy path”

Why: Faster setup → more installs.

  1. Add 3 screenshots (launch UI, load extension, run Neo4j query).
  2. Insert numbered list in README.md under Quick Start.
  3. Link to troubleshooting page.

DoD: Section renders; links work; images <300KB.

Docs: GHCR “unauthorized” troubleshooting

Why: Common first-run blocker.

  1. Create docs/troubleshooting.md entry on GHCR login.
  2. Add CLI snippet to authenticate and retry pull.
  3. Link from README Quick Start.

DoD: Steps verified on Win/macOS/Linux; anchors updated.

Examples: Starter Cypher queries

Why: Instant success in Neo4j.

  1. Add /examples/cypher/starter.cypher with 6 queries.
  2. Reference from README and Quick Start.

DoD: Queries run on demo data.

NLP: phrases.yml wired to text_topic_analysis.py

Why: Stable multi-word expressions improve “aboutness.”

  1. Create config/phrases.yml with seed entries.
  2. Merge matched phrases before TF-IDF (no renames).
  3. Add unit tests + eval notebook.

DoD: Phrases appear as single terms; tests green.

NLP: Configurable TF-IDF threshold

Why: Reduce noise & storage.

  1. Add min_topic_score to config.json.
  2. Filter below threshold before writing to SQLite/Neo4j.
  3. Log filtered counts at DEBUG (no prints).

DoD: Threshold respected; docs updated.

Ingest: Watched folder scaffold

Why: Zero-auth path boosts adoption.

  1. Create data_sources/watched_folder.py with watchdog.
  2. Parse .md/.txt/.html; write events via current API.
  3. Doc: “Point Coyote at a folder.”

DoD: Drops → Document nodes in ~10s on all OSes.
