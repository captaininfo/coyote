🚀 Quick Start

Follow these steps to get Coyote up and running:

  1. Configure Neo4j Database - Set up your personal knowledge graph
  2. Install Browser Extension - Enable web browsing data capture
  3. Optional: Connect Integrations - Link external platforms like Hypothes.is
  4. Start Learning - Begin browsing and let Coyote track your journey
